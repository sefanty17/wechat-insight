# 家教个体户视角：微信群线索抽取工具的 6 轮真实使用模拟

> **人物设定**：老周，28 岁，全职家教个体户，手上 7 个学生（初中数学 / 物理为主）。
> 活跃在 13 个家长群 + 小区群，另有 20 多个家长私聊。每天早晚各刷一次微信，**手机上用为主**，偶尔开电脑。
> 工具现状：6 个内置模板（家教辅导等）→ 多选要扫描的会话 → 选时间范围 → 开始抽取 → 一张表（每行一个实体，列为模板字段）→ 单框搜索（精确/模糊）、时间倒序、导出 CSV。

---

## 第 1 轮｜第一次用：想看看这工具到底能给我捞出什么

**1. 此刻想干什么**
刚被一个学生退课，手上空出周二、周四晚。想从最近两周的群消息里翻翻有没有新找家教的家长。手动翻 13 个群，一晚上都翻不完，所以想试试这个工具。

**2. 我会怎么操作**
打开网页 → 模板选"家教辅导" → 会话多选里勾 6 个"XX 家长交流群"、3 个小区群、2 个家长私聊 → 时间范围选"最近 7 天" → 点"开始抽取"。

**3. 哪里不够用 / 很别扭**
- **多选下拉里只有会话名，没有"最近有没有消息"**。"阳光花园②群"和"阳光花园(新)"我分不清哪个是活的，勾错了就白扫一遍。30 多个会话也没法按"最近活跃"排。
- **抽取前我心里没底**：要扫多少条？要多久？我 7 天的聊天记录会不会被传走？家长群里全是别人家孩子的成绩、电话、住址，**页面上没有任何隐私说明**，我第一反应是不敢点。
- **结果 60 多行里一大半是废话**："有没有老师推荐""孩子数学跟不上"这种没有具体信息的闲聊，还有几条是别的家教在打广告。我真正能用的也就 15 条。
- **表头的"状态"列我不知道是谁填的、按什么填的**，格子里的词（"待沟通"？）我不敢信，也不知道能不能改。
- **空格子不知道是"消息里没说"还是"工具没抓到"**，这俩含义差很远：前者我认，后者说明工具不行。

**4. 希望它变成什么样**
- 选会话时能看到**每个会话"最近消息时间 + 近 7 天消息量"**，能按最近活跃排序、能把我星标的群置顶。
- 抽取前有一句明确交代：这次扫哪几个会话、扫了多少条、数据存在哪、能不能一键删除。
- 结果里**自动分出"有效线索 / 纯闲聊 / 同行广告"**三类，闲聊默认折叠，别一上来糊我 60 行。
- 空字段显示"**未提到**"而不是空白。

## 第 2 轮｜找到线索了，开始跟进：我要的是"这周新增 + 没联系过 + 课时费>150"

**1. 此刻想干什么**
第一轮捞出 20 多条像样的线索。现在我只想要**这周新冒出来的、我还没联系过的、课时费不低于 150 的初中数学**，一次性排出来，今天挨个加微信。

**2. 我会怎么操作**
搜索框输入"150" → 精确匹配 → **没结果**（人家写的是"一小时 150""150-200""面议"）。
改成模糊匹配 → 出来一堆，但"150"还能命中"1502 室""15:00"。
想再加"数学"这个条件 → **发现加不上**，搜索框只有一个，输入新词就把上一个条件顶掉了，只能重新筛。

**3. 哪里不够用 / 很别扭（本轮是重灾区）**
- **只有一个搜索框，只能一个词**。我真正想要的是"科目=数学 **AND** 课时费≥150 **AND** 地点含某片区 **AND** 我还没联系过"，**做不到**。每次只能筛一个条件，剩下的靠肉眼在 200 行里二次过滤。
- **没有"我处理到哪一步"的状态，而且不能自己改**。我分不清哪些是新线索、哪些我昨天已经加过微信。我只能另外拿手机备忘录记，**工具等于白用**。
- **没有"我上次看过了"的概念**。昨天筛过一遍，今天再抽一次，昨天的和今天的混在一起，我得从头再认一遍脸。
- **同一个家长在 3 个群里发了同一段话，表格里就是 3 行**，我差点以为是 3 个客户，加了同一个人两次。
- **课时费不是一个数**（"150-200""一小时一百五""面议"），没法按数值筛、没法按价格排序。而我最想看的就是"贵的先看"，现在只能按时间倒序。
- **联系方式不能一点就复制**。手机号散在格子里，手机上长按选中还会带出旁边的字，一条线索多花 20 秒。
- **时间字段是自由文本**（"周三晚 7 点""周末都行"），没法跟我自己的空档（周二、周四晚）匹配。

**4. 希望它变成什么样**
- **多条件组合筛选**：科目 / 年级 / 地点 / 课时费（数值区间）/ 可上课时段，几个控件叠着用；并且能**存成"我的常用视图"**（如"初二数学 · ≥150 · 未联系"），下次一点就出来。
- **加一列我自己能点的"跟进状态"**（新线索 → 已联系 → 试听中 → 已成交 → 已放弃）+ 备注 + 时间戳。
- **"只看新增"开关**：跟上次扫描结果对比，只显示新出现的，并打"NEW"标。
- **自动去重合并**：同联系方式 / 同文本跨群合并成一行，后面标"来源：3 个群"。
- **课时费解析成可排序的数值区间**（"150-200" → 150），支持"课时费从高到低"。
- 联系方式/地址**一键复制**，还能一键套用邀约话术模板（"您好，看到您在群里找数学老师…"）。

## 第 3 轮｜跟进一两周后：我记不清谁是谁了，需要一条线索的完整过程

**1. 此刻想干什么**
手上 12 条在跟的线索。有的聊过两次，有的试听完家长说"再商量"。我想在**一条线索底下**看到：哪个群来的、第一次什么时候出现、我什么时候联系的、聊到哪一步、下次该什么时候问。

**2. 我会怎么操作**
在表格里找到那个家长 → 想点开看看 → **发现整行是死的**，点哪儿都没反应，只有那几个字段。

**3. 哪里不够用 / 很别扭**
- **每一行只是"一条消息的快照"，不是"一个人"**。那个家长这周又问了一次"老师还带吗"，工具又抽了一行新的，跟我上周标记过的那条对不上，等于同一个人裂成两条。
- **不能写备注**。我想写"妈妈说等孩子期中考完再定，10 月中旬再问"——没地方写。
- **没有提醒**。说好"一周后问"，一周后我肯定忘。
- **不能手动补、不能改**。家长在私聊里给了微信号，工具没抓到，我想手动加一行也不行；抽错的（把"200"当成年级）也改不了。
- **不能删/隐藏**。明显是同行广告或者已经明确不找了的，我想从列表里划掉，只能忍着看它一直在。

**4. 希望它变成什么样**
- 点一行能展开**线索详情 / 时间线**：首次出现时间、来源会话、原始消息原句、我的备注、每次跟进记录（一条一条带日期）。
- 能把两行**合并成同一个人**，也能**手动新增一行**、**编辑任意字段**、**标记无效并隐藏**。
- 每条线索能设**跟进提醒**（"10 月 15 日提醒我"），到点在页面顶部有个"今天该跟进"的待办区。这是我每天最想看的视图。

## 第 4 轮｜量大了：攒了两三百行，每次全量重扫，表格开始没法用

**1. 此刻想干什么**
用了三周，累计 280 多条（含已成交、已放弃）。我实际只想管"在跟的 12 条"+"这周新增的 8 条"，其余都是历史。

**2. 我会怎么操作**
又勾 13 个群、扫最近 7 天 → 结果 200 多行里混着一堆老的，按时间倒序翻到第 3 屏就放弃了。

**3. 哪里不够用 / 很别扭**
- **每次都全量重扫，结果既不累积也不增量**。要么每次重新认一遍，要么老数据丢了。**没有"这条我处理过了"的记忆，扫描就是白扫。**
- **列表没有数量统计、没有分页**。我不知道现在到底有多少条待处理，滚轮滚到怀疑人生。
- **没有归档**。成交的和放弃的混在列表里，噪音越来越大，真正要跟的被淹没。
- **没有批量操作**。20 条同行广告，我想一次全标无效，只能一条条点。
- **重复线索越来越多**：同一个家长名字写法不同（"乐乐妈""乐乐妈妈""李女士"），去重也去不掉。
- **手机端没适配**。我在外面等学生下课想刷一眼，表格要左右拖，字段一多根本看不全。

**4. 希望它变成什么样**
- **增量抽取**：扫描结果和历史库合并，只标"新增"，已处理的保持我设的状态，别再让我重新认。
- 列表顶部**按状态计数**：新线索 8 / 跟进中 12 / 已成交 3 / 已放弃 40，点一下就是过滤器。
- **归档 + 回收站 + 批量选择**（批量标无效、批量改状态、批量设提醒）。
- 表头固定、**列可自定义显示/隐藏**、支持分页；**手机端做成卡片流而不是大表格**。
- 相似线索给**合并提示**："疑似同一人（乐乐妈 / 李女士），是否合并？"

## 第 5 轮｜想复盘：这个月到底赚了多少、哪个群最出活

**1. 此刻想干什么**
月底了。想知道：这个月捞到多少条线索、联系了多少、试听多少、成交几个、成交均价多少、**哪几个群最出活**、哪个科目问的人最多。以后好决定精力往哪放。

**2. 我会怎么操作**
导出 CSV → 打开 Excel → 想做个透视表 → **发现做不了**：课时费是"一小时 150-200"这种文本，状态列是空的，"来源"这列**根本不存在**（我不知道每条来自哪个群）。

**3. 哪里不够用 / 很别扭**
- **没有来源字段**。我一直想知道"阳光花园群"和"XX 小学家长群"哪个出活，表里不记录来自哪个会话。
- **导出的是抽取到的原始字段，不是我的跟进数据**。我标的"已成交""已放弃"、我的备注，导出后全没了。
- **完全没有统计视图**。转化漏斗、均价、按群/按科目的分布，全靠手工算，算一次一小时。
- **导出之后回不去**。我在 Excel 里改完，网页这边还是老样子。
- **CSV 在手机上打开是乱码/挤成一列**，我大部分时候都在手机上。

**4. 希望它变成什么样**
- 每条线索**记录来源会话**（哪个群 / 哪个好友）。
- 一个**复盘页**：本月新增 / 已联系 / 已试听 / 已成交 / 转化率 / 成交均价 / 按来源群排行 / 按科目排行，最好能按周看趋势。
- **导出带我自己的跟进状态和备注**（而不是只导抽取字段），并且**导出的是当前筛选视图**，最好还能**导回来**。
- 导出给两个选项：CSV（电脑用）和**手机能直接看的长图 / 纯文本清单**。

## 第 6 轮｜想给同行看：把一条线索转给搭班老师

**1. 此刻想干什么**
我周二、周四排满了，想把手里一条"初三物理"的线索转给搭班的老师；也想让同行看看我在这个小区群的出活情况，顺便问问他那边有没有我要的初中数学。

**2. 我会怎么操作**
想挑几条线索发给他 → 直接导 CSV 发微信 → **手停在发送键上了**：CSV 里全是家长手机号和住址，直接发出去就是泄露隐私，而且他手机上根本打不开。

**3. 哪里不够用 / 很别扭**
- **没有分享 / 协作**。要么整表截图（信息全暴露），要么手打几条发过去，效率极低。
- **没有脱敏导出**：联系方式能不能打码（138\*\*\*\*1234）、能不能只勾选"这几条"导出去，都做不到。
- **没有只读链接**。我希望生成一个链接，他打开就能看这几条，但看不到手机号，也改不了我的表。
- **没有"已转介"状态**。线索给了同行，表里还是"跟进中"，过两周自己都记混了。
- 同行不用这个工具，所以链接必须**不用注册、打开即看**，而且在微信里打开要好看。

**4. 希望它变成什么样**
- 勾选若干条 → **生成分享链接 / 分享卡片**，可选是否包含联系方式（**默认打码**）、可选只读。
- **导出时自己勾列**（哪些字段导、联系方式是否打码）。
- 线索上加"**已转介 / 已交给他人**"状态 + 备注（转给谁、什么时候）。
- 分享页在手机微信里是卡片式，能一键拨号 / 复制微信号（没打码时）。

## 按优先级排序的改进清单（8 条）

| # | 改进项 | 解决什么问题 |
|---|---|---|
| 1 | **多条件组合筛选 + 保存常用视图** | 解决"这周新增 + 未联系 + 课时费≥150 + 指定科目/片区"这种组合条件**根本表达不出来**，只能单关键词搜、再靠肉眼在几百行里二次过滤的问题（第 1/2/4 轮反复卡住）。 |
| 2 | **线索级跟进状态 + 备注 + 时间线**（把"消息快照"变成"客户档案"） | 解决表格是死的、我不能标记"已联系/已成交"、第二天分不清谁新谁旧、聊到哪一步全靠脑子记的问题。**这是从"抽信息"到"管线索"的关键一跃。** |
| 3 | **增量抽取 + 新增(NEW)标记 + 跨扫描记忆** | 解决每次全量重扫、新老线索混在一起、我已处理的记录丢失、**扫描等于白扫**的问题。 |
| 4 | **自动去重合并 + 相似线索合并提示** | 解决同一家长在多个群发同样消息被算成多个客户、加错人、列表噪音大的问题。 |
| 5 | **关键字段结构化**：课时费→可排序数值区间；时间→可用的上课时段标签 | 解决"150-200""面议""周三晚 7 点"没法筛选、没法按价格排序、没法跟我自己的空档匹配的问题。 |
| 6 | **状态计数 + 归档 + 批量操作 + 移动端卡片视图** | 解决量到几百条后表格滚不到底、成交和放弃混在一起、无法批量清理、手机上看不全的问题。 |
| 7 | **复盘统计页 + 来源追踪 + 带跟进数据的导出/回导** | 解决月底算不出转化率和均价、不知道哪个群最出活、导出的 CSV 只有原始字段没有我的跟进结果的问题。 |
| 8 | **脱敏分享 / 只读链接 + 自选导出字段 + "已转介"状态** | 解决把家长手机号直接甩给同行会泄露隐私、同行手机上打不开 CSV、转出去的线索自己还记成"跟进中"的问题。 |

### 没进前八但直接影响"我敢不敢用"的两点
1. **首次扫描前的透明说明**（扫了哪些会话、多少条、数据存哪、能否一键删除）。家长群里是别人孩子的隐私，**这一步缺席，我可能根本不敢把群交给它扫**。
2. **联系方式一键复制 + 邀约话术模板**。纯效率项，但每条线索省 20 秒，一天 20 条就是 7 分钟。

---

## 一句话结论

这个工具目前是「**信息抽取器**」——它回答"群里说了什么"；
但家教个体户真正的工作流是「**线索管道**」——我要回答"**谁是新客户、我跟到哪一步了、下一个该联系谁、这个月哪来的活最值钱**"。
6 轮里所有的别扭，几乎都能归到这一条落差上：**表格只记录消息，不记录我和这条线索之间的关系与时间。**
