# 微信群信息抽取工具 · 真实用户需求挖掘（6 轮模拟）

> **模拟角色**：阿哲，大二，全校最大的 500 人「XX大学兼职&二手&球局总群」的义务信息整理员。
> 他每天在这个群里帮同学捞兼职、盯羽毛球局、蹲便宜二手货，还要应付群里七嘴八舌的通知。
> 他每天早晚各刷一次群，看到有用的就手动转成文字/截图发到自己的小群和朋友圈。

---

## 第 1 轮：第一次上手——「我先试试它到底能不能读懂这个群」

### 1. 此刻想干什么
群里昨晚又刷了 300 多条。我不想一条条翻，先想看看这个工具到底能不能把"兼职"和"通知"分出来，值不值得以后天天用。

### 2. 我会怎么操作
- 模板选「群聊情报」（因为我要的是"信息+要做什么"，不是单纯的家教或团购表）。
- 在会话多选下拉里搜"兼职"，勾上「XX大学兼职&二手&球局总群」，顺手把「羽毛球局①群」「二手闲置A群」也勾上。
- 时间范围选「最近 3 天」。
- 点「开始抽取」，等结果。

### 3. 哪里不够用 / 很别扭
- **我最开始根本不知道该选哪个模板。** 6 个模板名字都挺像，"群聊情报"和"自定义"到底差在哪、哪个字段多、哪个能抽时间，页面上完全没说明。我只能一个个点开试，试错成本高。
- **多选下拉里会话太多、看不出来谁是谁。** 500 人群和几十个小群混在一个列表里，只有名字、没有"最后活跃时间/成员数/今日消息数"。我不知道该勾哪个，也不知道哪个群今天其实根本没消息，白扫一遍。
- **时间范围只有粗粒度选项。** 我想选"昨晚 20:00 到现在"这种，因为白天的聊天都是水，只有晚上 8 点后才是老师和中介发兼职的黄金时段。工具给不了。
- **我不知道它在抽的时候到底读了多少条、跳过了多少条。** 结果出来直接就是表格，我心里没底：是这 3 天就 12 条有用信息，还是它只读了 50 条就停了？

### 4. 我希望它变成什么样
- 每个模板带**一句话说明 + 字段预览**，最好直接写"适合：群里有人说话、需要知道谁该干什么"。
- 会话选择列表加上**今日消息数、最后活跃时间、成员数**，再加"最近有新消息的群置顶"，以及一个"只看未读/有新消息的群"开关。
- 时间范围支持**自定义区间 + "昨晚 20 点后""周末""工作日白天"这类保存好的时段**。
- 抽取开始前先给个**预处理摘要**："共扫描 3 个群 / 847 条消息 / 识别到 213 条疑似情报 / 已合并重复 41 条"。

---

## 第 2 轮：结果太多——「我要的不是 200 行，是 5 行」

### 1. 此刻想干什么
抽完了，240 行。我真正要看的可能就 5～8 条：今天能报名的兼职、今晚没满的球局、有人便宜出我想要的显示器。剩下的全是"哈哈哈""收到""+1"抽出来的垃圾。

### 2. 我会怎么操作
- 用搜索框分别搜"兼职""球局""显示器"，一个个词试着捞。
- 按时间倒序从头往下扫，扫到第 40 行眼睛就花了。

### 3. 哪里不够用 / 很别扭（本轮最难受）
- **只有一个搜索框，没有"字段级筛选"。** 我最想做的就是「类型 = 机会 **且** 紧急度 = 高」，但搜索框只能一个词一个词搜，还没法组合条件。搜"机会"会把"类型"和"要做什么"里所有出现"机会"的行都翻出来，噪音爆炸。
- **没有真正的"多条件筛选器"。** 我想要的是：类型多选（机会 + 需要跟进）、紧急度多选（高）、时间在今天之后，三个条件叠加，而不是去猜关键词。
- **搜索是"字符串匹配"不是"语义理解"。** 群里有人写"有想去当家教的不，一小时 80"，也有人写"招个陪练"，我搜"兼职"根本搜不到，因为它们字面上不含"兼职"两个字。这条信息等于丢了。
- **抽出来的行看不出"为什么是它"。** 表格里只有事项、相关人、时间，没有**原始消息出处**。我没法判断这条是真机会还是有人在开玩笑，也没法点进去看上下文。
- **没有排序之外的"分组/折叠"。** 240 行平铺，其实里面"兼职"占 60 行、"球局"40 行、"通知"100 行。我希望能按类型先分组，组内再按紧急度排，一眼看到结构。
- **没有"置顶/标记重点"。** 我看到一条特别好的（比如"字节实习内推，今晚截止"），除了自己记在小本本上，工具里没法标一下，下次滚下去就找不到了。

### 4. 我希望它变成什么样
- 把搜索框升级成**筛选面板**：类型、紧急度、时间、相关人、是否已处理，做成多选 chips，可以叠加，并在界面顶部显示"当前条件：类型=机会 且 紧急度=高，命中 7 条"。
- 搜索要**能搜到意思**：搜"兼职"能带出"招人""找家教""陪练""日结"这类同义说法（语义/同义词扩展），而不是死磕字面。
- 每行加**"为什么抽出来"的解释**：可展开的原始消息片段 + 谁在什么时候说的 + 置信度（高/中/低）。
- 表格支持**按类型分组折叠**，组头上直接写"N 条 / 高紧急 M 条"。
- 加**星标/重要标记**列，标记的行固定置顶。

---

## 第 3 轮：想让它自动推给我——「我不想每天手点 4 次」

### 1. 此刻想干什么
我已经连用了 5 天。每天早晚各点一次"开始抽取"、再筛一次、再扫一遍，重复劳动。我想要的是：**早上 7:50 我刷牙的时候，手机里就有一份"今天该看的 6 条"**，而不是我坐到电脑前手动跑。

### 2. 我会怎么操作
- 每天手动选同样的会话、同样的时间范围、点同样的按钮。
- 抽完再手动筛"机会 + 高紧急"。
- 然后手动导出 CSV，或者截图发小群。

### 3. 哪里不够用 / 很别扭
- **完全是一次性的，没有任何"保存配置"的概念。** 我每天要重复选择的会话、时间范围、筛选条件，第二天全部清零，得从头选一遍。我甚至没法给它起个名字叫"兼职日报"。
- **没有任何推送/订阅能力。** 没有"定时任务"，没有"到点发我微信/邮件/浏览器通知"。这个工具被动得像个手动榨汁机。
- **导出 CSV 对我没用。** 我是要在手机上、在群里看，不是要在 Excel 里做分析。我要的是**一段可以直接复制粘贴/转发的话**（比如"今日兼职 3 条：1)...2)..."），CSV 反而帮倒忙。
- **没有"增量"概念。** 我昨天已经看过的 200 条，今天重新抽一遍又全出来了，我得重新扫一遍去认哪些是新的。**每天真正的新信息可能只有 10 条，但我每天都要为旧的 200 条付出一遍注意力。** 这是最贵的时间成本。

### 4. 我希望它变成什么样
- 支持**把"模板 + 会话 + 时间范围 + 筛选条件"保存成一个叫"兼职日报"的任务**，一键复用。
- 支持**定时执行 + 主动推送**：每天 7:50 自动跑，结果用微信/邮件/浏览器通知推给我，推送内容只要 Top 5～10 条高优先的，并附"查看全部"链接。
- 推送格式要**可直接转发**：生成一段排版好的短文本/图片卡片，我复制就能发小群。
- 要有**增量模式**："只给我上次之后的新消息"，并且在界面上明确区分"新增 N 条 / 上次遗留 M 条 / 已处理 K 条"。

---

## 第 4 轮：抽得出来 ≠ 重要——「工具抓关键词，我抓人」

### 1. 此刻想干什么
我发现自己其实**不是在找"兼职"两个字，我是在盯三个人**：群里的中介老张（他发的都是真机会）、班长小李（他发的是官方通知，必须看）、还有个二手贩子阿强（他发的便宜货秒没，得第一时间抢）。其他人刷屏 100 条我也不看。

### 2. 我会怎么操作
- 搜相关人"老张"，看他说了什么。
- 或者干脆放弃工具，直接去群里点开老张的头像看他的聊天记录。

### 3. 哪里不够用 / 很别扭（本轮的关键洞察）
- **"顺带提到" vs "真正重要"完全分不开。** 真正重要的往往是那种一句话带过的——"对了，明天下午三点球局少一个人"——它没有"通知""机会"这类关键词，紧急度也可能被抽成"低"，结果被埋在第 180 行。而重复刷屏的"求兼职！求兼职！"被抽成高紧急，占满前面。
- **相关人筛选不存在。** 表格里有"相关人"这一列，但它**不能作为筛选条件**。我就想"只看老张、小李、阿强三个人相关的行"，做不到，只能靠搜索框碰运气匹配字符串。
- **没有"关注人/黑名单"机制。** 我不能把老张标记为"值得关注的来源"，把他的消息自动升级优先级；也不能把某个刷屏水友屏蔽掉。
- **没有"我关心的话题"概念。** 我关心的是"显示器、键盘、羽毛球、日结 200 以上、图书馆附近"，工具不知道，只能靠我每次手动筛。
- **紧急度判定不可解释也不可纠正。** 它说这条"低"，我觉得是"高"，但我改不了，也没法训练它。下次还是同样的错。

### 4. 我希望它变成什么样
- 加**"关注来源"**：把某些人/某些群设为核心来源，他们的消息自动提优先，并在结果里高亮。
- 加**"屏蔽来源/屏蔽词"**：某个水友、某些套话直接过滤掉，从结果里消失。
- 加**"我的关注词/关注话题"**：显示器、球局、日结、图书馆附近……匹配到的行自动加权。
- 紧急度要**可解释、可纠正**：告诉我为什么判成"高"（比如"含截止时间""@全体成员"），并允许我手动改，改完要能影响后续判定和筛选。
- 增加一列/一个维度：**"是否顺带提及"**（在长对话中被夹带说出的关键信息），把这部分单独拎出来看，而不是和刷屏混在一起。

---

## 第 5 轮：处理状态——「我处理过的，别再出现了」

### 1. 此刻想干什么
昨天看到"健身房兼职，联系王姐"，我已经加了微信并约好了。今天抽取结果里它又出现了，我又点开一次才发现是旧的。这种"重复消费"每天浪费我十几分钟，而且很烦——我甚至开始怀疑工具有没有在认真工作。

### 2. 我会怎么操作
- 手动在脑子里记"这条处理过了"。
- 或者自己在 Excel/备忘录里另外维护一张"已处理清单"，跟工具的表格做对照。

### 3. 哪里不够用 / 很别扭
- **完全没有"已处理 / 已忽略 / 待跟进"的状态。** 每条信息都是一次性的、无状态的，工具不记得我对它做过什么。
- **没有跨天去重。** 同一条消息在"最近 3 天""最近 7 天"的不同抽取里会反复出现，工具不做任何统一标识。
- **没有"待跟进"清单。** 有些信息我现在处理不了，比如"下周三才开始报名"，我需要它以"待办"的形式留到那天再提醒我，而不是混在今天的流里被我划掉后彻底消失。
- **没有操作留痕。** 我点过"这条我看过了"没有，工具无从知道，所以也没法做到"默认只显示未处理"。

### 4. 我希望它变成什么样
- 每行有**状态字段**：未处理 / 待跟进 / 已处理 / 已忽略，可一键切换。
- 默认视图**只显示未处理**，已处理折叠起来，并提供"只看待跟进"的标签页。
- 状态**持久保存**，跨天跨次抽取都有效；同一条原始消息要有稳定 ID，**全局去重**，已处理的不再作为"新信息"出现。
- "待跟进"支持**设置提醒时间**（下周三 9 点提醒我报名）。
- 加个**每日小结**："今天新增 12 条，已处理 9 条，待跟进 3 条"，让我有掌控感。

---

## 第 6 轮：常态化之后——「我想要的其实是一个助手，不是一个表格」

### 1. 此刻想干什么
用了三周，我已经完全清楚自己每天看什么。现在我想的是：
- 早上起来看一条**汇总推送**（5 条重点 + 1 句总结）。
- 有真正紧急的（比如"今晚 8 点球局缺人，速来"）能**立刻响我一下**，不用等到第二天早上。
- 我处理不了、需要同学帮忙的（比如"帮发个兼职信息给 3 个班群"），能**一键转/指派**出去。
- 月底我想回看：这个月我一共捞到多少兼职、成单了几个、哪些来源最靠谱。

### 2. 我会怎么操作
- 现在只能靠"早晚手动跑 + 截图转发 + 备忘录记账"，工具只承担了"抽取+表格"这一段，前后全靠我自己。

### 3. 哪里不够用 / 很别扭
- **工具止步于"表"，没有闭环。** 从"看到信息"到"处理完信息"中间的全部分（提醒、转发、指派、复盘）都要我手工补，工具一点忙帮不上。
- **没有分层推送。** 所有信息一个待遇，我要么全看要么全不看，没有"紧急的立刻推、普通的早上汇总、次要的周末汇总"这种分级。
- **没有来源质量统计。** 我不知道老张发 20 条里成 15 条、水友发 50 条里成 0 条。要是有这个数据，我早就把水友屏蔽了，工具的"关注来源"也能自动推荐。
- **不能协作。** 我是帮同学捞信息的，但工具是我一个人的黑盒，同学看不到、我也没法把某条直接甩给对应的人。
- **没有历史回顾/趋势。** 我想知道"这周兼职数量比上周少了 30%""球局集中在周三周五"这类信息，一次都拿不到。
- **筛选条件组合越用越多，却没有"保存视图"。** 我每次都要重新拼"机会+高紧急+未处理+关注来源"这四个条件。

### 4. 我希望它变成什么样
- 做**分级通知**：紧急（立刻推）/ 重要（每日汇总）/ 普通（每周汇总），规则可由我配置。
- 加**来源质量榜**：按来源统计"命中数 / 已处理数 / 我标为重要的数"，用来推荐该关注谁、该屏蔽谁。
- 支持**一键转发/指派**：把某条信息直接生成转发文案，或指派给某个同学。
- 支持**保存视图**（Saved View）：把我常用的筛选组合存成"我的今日待办"，一键进入。
- 提供**周报/月报**：数量趋势、类型分布、来源分布、我的处理率。

# 按优先级排序的改进清单（最多 8 条）

| 优先级 | 改进项 | 解决什么问题 |
|---|---|---|
| **P0** | **把单搜索框升级为多条件筛选面板**（类型 / 紧急度 / 时间 / 相关人 / 处理状态，可多选叠加） | 直接解决"想按 类型=机会 且 紧急度=高 筛但只有一个搜索框"——这是每天最高频、最卡手的动作 |
| **P0** | **处理状态 + 全局去重**（未处理/待跟进/已处理/已忽略，同一条原始消息稳定 ID、跨天不重复出现，默认只看未处理） | 解决"我处理过的别再出现"，消除每天为旧信息重复付出的注意力成本，也给"待跟进"提供落脚点 |
| **P0** | **保存任务 + 定时执行 + 主动推送**（模板+会话+时间+筛选存成"兼职日报"，每天定点自动跑并推送，支持增量模式） | 解决"想让工具每天推给我，而不是每次手动点"，把每次手动四步操作变成零操作 |
| **P1** | **关注来源 / 屏蔽来源 / 关注词加权**（核心人自动提优，水友和套话自动过滤） | 解决"抽得出来的和真正重要的不一致"——真正重要的是**人**和**话题**，不是关键词；同时压掉大量噪音 |
| **P1** | **语义搜索 + 同义词扩展**（搜"兼职"能带出"招人/家教/陪练/日结"） | 解决关键词字面匹配漏掉大量真实机会，以及"顺带提到"的信息检索不到 |
| **P1** | **每条结果可展开原文出处 + 判定理由 + 可纠正的紧急度**（含"是否顺带提及"标签） | 让用户能信任和校正结果，把被埋在第 180 行的关键信息拎出来，解决"黑盒不敢用" |
| **P2** | **结果分组折叠 + 星标置顶 + 可保存视图**（按类型分组，组头显示数量与高紧急数，常用筛选组合存成"今日待办"） | 解决"240 行平铺扫不动"和"每次都要重新拼筛选条件"，把降噪从"逐行扫"变成"看结构" |
| **P2** | **可直接转发/指派的推送文案 + 来源质量榜 + 周月报** | 解决"工具止步于表格、前后全靠手工"，让信息能流转给同学，并用数据反哺"该关注谁、该屏蔽谁" |

## 一句话总结

这个工具现在的定位是"**帮我抽取信息**"，但用户真正要的是"**帮我只看见那 5 条必须看见的，并且别让我看第二遍**"。
所以改进的主轴不是"抽得更准"，而是三件事：**降噪（分层筛选 + 来源加权）、记住（处理状态 + 去重）、主动（定时推送 + 分级通知）**。
