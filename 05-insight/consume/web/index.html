计价公式
输入费用 = 输入tokens / 1e6 × 输入单价
输出费用 = 输出tokens / 1e6 × 输出单价
缓存费用 = 命中缓存的输入tokens / 1e6 × 缓存单价
思考费用 = 思考tokens / 1e6 × 输出单价 × 思考倍率
─────────────────────────────────────
合计     = 输入 + 输出 + 缓存 + 思考

思考 token 不是常数，而是一个函数：
  思考 = 基准 + 放大系数 × 输入token × 内容密度   （设上限）
其中内容密度：报错 2.2 > 代码 2.0 > 链接 1.8 > 疑问 1.5 > 普通 1.0
              > 纯表情 0.15 > 短确认 0.12
所以「回一句嗯」和「回一段报错分析」的思考成本差两个数量级。
